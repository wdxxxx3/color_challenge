# Solv 空间漫游

一个基于 Three.js 的实验性小游，演示如何在三维 Solv 几何空间中移动。玩家使用第一人称视角，移动速度会随高度改变以反映 Solv 空间的度量特性。

## 功能特性

- 🧭 第一人称视角，支持鼠标指向与键盘移动。
- 🌀 根据 Solv 空间度量调整的横向移动速度，展现各高度下的各向异性。
- 🌐 多层网格、流线与粒子效果帮助理解空间结构，并提供实时 HUD 信息。

## 操作说明

- `W`/`S`：沿视线方向前进/后退。
- `A`/`D`：向左/向右平移。
- `Space`/`Shift`：上升/下降；亦可使用 `Q`/`E`、`C`。
- 鼠标移动：转动视角。
- `R`：回到初始位置。
- `Esc`：退出游玩模式。

## 本地运行

本项目是纯静态页面，可使用任意静态文件服务器运行。例如使用 Python：

```bash
python3 -m http.server 8000
```

然后在浏览器访问 <http://localhost:8000>，点击页面进入体验。

也可以使用其它本地服务器（如 `npx serve`、`npx http-server` 等）。
