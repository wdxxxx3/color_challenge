# 颜色敏锐度挑战

一个轻量级的网页小游戏，训练你对颜色的敏锐度。每一关都会出现一组色块，其中仅有一个颜色略有不同，找到它即可晋级。共 12 关，难度会随着关卡逐渐提升，最终会统计得分与正确率，并记录历史最高分。

## 功能亮点

- ✅ 渐进式难度：色块数量和颜色差异会随着关卡提升逐步增加挑战性。
- ✅ 实时反馈：及时展示当前关卡、得分、历史最高分以及进度条。
- ✅ 结果统计：完成挑战后自动计算本次成绩和正确率，并支持再次挑战。
- ✅ 视觉体验：使用柔和渐变背景和动态动画，带来舒适的练习过程。

## 使用方式

1. 克隆或下载本仓库。
2. 使用任意静态资源服务器（如 `python -m http.server`）或直接打开 `index.html` 文件即可体验游戏。

```bash
python -m http.server 8000
```

随后在浏览器访问 [http://localhost:8000](http://localhost:8000)。

## 技术栈

- 纯 HTML + CSS + 原生 JavaScript 构建，无需任何构建步骤。
- 使用 `localStorage` 记录历史最高分。

欢迎体验并挑战你的极限色彩辨识度！
